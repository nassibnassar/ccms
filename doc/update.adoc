==== update

Update object attributes

[source,subs="verbatim,quotes"]
----
update `**_project_name_**`.object
    set `**_attribute_**` = { `*_value_*` | null } [, ...]
    [ where `*_search_condition_*` ]
----

[discrete]
===== Description

The `update` command changes the value of specified attributes for
selected objects.

Note that the values of updated attributes are shared by all sets
within a project.

[discrete]
===== Parameters

The first argument specifies the object set to be updated.

[discrete]
====== set

The `set` clause specifies the attributes to set and their new values.

[discrete]
====== where

The optional `where` clause specifies a search condition in the form
of a Boolean expression.  If the `where` clause is present, only
objects that satisfy the condition will be updated; otherwise all
objects will be updated.

See also *Reference > Queries*.

[discrete]
===== Examples

To set the decision and fund in an object having ID = 12:

----
update myproj.myset set decision = true, fund = cultural where id = 12;
----
