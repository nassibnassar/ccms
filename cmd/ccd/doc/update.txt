update

Update object attributes

update project_name.object
    set attribute = { value | null } [, ...]
    [ where search_condition ]

Description

The update command changes the value of specified attributes for selected
objects.

Note that the values of updated attributes are shared by all sets within a
project.

Parameters

The first argument specifies the object set to be updated.

set

The set clause specifies the attributes to set and their new values.

where

The optional where clause specifies a search condition in the form of a Boolean
expression. If the where clause is present, only objects that satisfy the
condition will be updated; otherwise all objects will be updated.

See also Reference > Queries.

Examples

To set the decision and fund in an object having ID = 12:

update myproj.myset set decision = true, fund = cultural where id = 12;
